# Insect-Detection
ROADMAP TO CREATING AN OBJECT DETECTION TFLITE MODEL
1.	Collect the dataset of images and label them to get their xml files.
2.	Install the TensorFlow Object Detection API.
3.	Generate the TFRecord files required for training. (need generate_tfrecord.py script and csv files for this)
4.	Edit the model pipeline config file and download the pre-trained model checkpoint.
5.	Train and evaluate the model.
6.	Export and convert the model into TFlite(TensorFlow Lite) format.
7.	Deploy the TFlite model on Android / iOS / IoT devices.
NOTE:- DETAILED EXPLAINATION FOR TRAINING THE MODEL ,GO THROUGH THE IPYNB FILE ATTACHED .
